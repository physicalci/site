Physical CI

What we're doing

Physical CI is working on how robotics teams test software changes on real robots before they ship: build, flash, boot, test, collect the results, and decide if the change is safe.

We're early. Right now I'm talking with robotics teams to learn how they test today and where it breaks.

My experience

  • Apple, 2020 to 2026. Five years getting operating system changes onto every Apple device without surprises. I qualified low-level OS changes across every platform, found which change in a batch broke things, backed it out, and built checks that caught bad changes before the expensive testing.
  • Northrop Grumman, 2.5 years. Global Hawk, an unmanned aircraft.
